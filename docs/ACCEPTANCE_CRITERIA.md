# 验收标准

## V2 验收标准

V2 的验收重点是质量控制流程是否完整、可解释、可复核，并且不会在用户确认前影响后续分析。

- 物理范围异常可以自动处理
- Hampel 和 constant_value 默认只标记，不自动删除
- 用户可以对候选点执行删除、保留和恢复
- physical_range 是硬规则，不可通过普通恢复操作恢复
- 后续重采样、统计、绘图和导出只使用 final_qc_data
- QC 日志可以追溯每个异常点的规则、原因、是否应用和用户决定
- 上传新文件或切换关键条件时会重置旧决策
- 用户确认最终质控结果后，才进入后续分析
- QC 日志可以导出
- depth 和 temperature 的 V1 基础分析结果不因 V2 质控流程而失效

## V3 验收标准

V3 的验收重点是变量扩展能力是否足够通用，新增变量时不应复制一套专用流程。

- 新增普通变量主要通过 variable_registry.py 完成
- metrics.py 不再按变量名称硬编码主要流程
- 支持不同采样频率
- 低频变量不会错误运行日内距平
- 每个变量可配置质控能力
- 每个变量可配置统计能力
- 每个变量可配置重采样能力
- 每个变量可配置绘图能力
- 支持盐度、溶解氧、pH、浊度、叶绿素、COD、BOD
- 多变量结果可以汇总导出
- depth 和 temperature 原有结果通过回归测试
