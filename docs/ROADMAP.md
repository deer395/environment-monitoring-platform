# 项目路线图

## V1：基础分析版本

目标是完成本地最小分析闭环，支持研究人员对水深和温度数据进行基础处理、统计和输出。

已覆盖能力：

- 水深、温度 Excel 数据读取
- hourly 和 daily 重采样
- 基础统计计算
- 基础图件生成
- Excel 结果导出

## V2：质量控制版本

目标是让质控过程可解释、可复核、可确认，并确保后续分析只基于最终质控数据。

核心能力：

- 变量注册表
- physical_range 自动处理
- Hampel 候选标记
- constant_value 候选标记
- 人工删除、保留、恢复
- QC 日志
- 质控确认后分析
- 缓存和 Plotly 交互

## V3：通用多变量版本

目标是从水深、温度专用流程扩展为通用环境监测变量分析框架。

规划能力：

- 通用变量架构
- 去除 depth/temperature 硬编码
- 支持 salinity、dissolved oxygen、pH、turbidity、chlorophyll、COD、BOD
- 按变量配置质控、重采样、统计和绘图
- 多变量汇总导出

## V4：调和分析版本

目标是在通用变量框架稳定后，为适用变量增加调和分析能力。

规划能力：

- 仅对支持调和分析的变量启用
- 分潮分析
- 振幅计算
- 迟角计算
- 拟合结果
- 残差分析
- 解释率输出

## V4.1.1：单变量自动报告

目标是在现有质控、重采样和统计基础上，完成单变量 Word 自动报告的最终收尾。

已完成能力：

- 本地确定性单变量 Word 报告
- 小时、日内距平、月平均三层描述
- 月平均多阶段识别与周期识别
- 温度单位统一为 `℃`
- 真实 PAHs、生化需氧量、水深、盐度和温度报告抽查

后续承接：

- V4.2 多变量综合 Word 报告
- V5 产品化整理与发布准备

## V5：自动报告版本

目标是在确定性计算和图件稳定后，生成结构化报告草稿。

规划能力：

- 数据概况说明
- 质控过程说明
- 统计结果说明
- 图件汇总
- 分析结果草稿
- 报告文本基于已计算结果生成
