# 项目路线图

## 月际叙述压缩（暂停）

月际叙述压缩已暂停，属于可选的后续优化，不是当前主线。当前正式路线继续使用 V4.2 确定性月际叙述和既有质量评估工具；仅当人工复核成为明显业务瓶颈且具备更充分标注数据或更稳健方案时，再重新评估。

## V1：基础分析

完成本地最小分析闭环，支持 Excel 数据读取、重采样、基础统计、图件生成和结果导出。

## V2：质量控制

完成可解释、可复核、可确认的质控闭环。physical_range 自动删除，Hampel 与 constant_value 仅生成候选，人工确认后的 `final_qc_data` 作为后续正式分析唯一数据源。

## V3：通用多变量

从水深、温度专用流程扩展为九个固定环境监测变量的通用处理框架。变量中文名、单位、范围和质控参数由注册表统一维护。

## V4.1.1：单变量确定性 Word 报告

已完成单变量 Word 报告、小时/日内距平/月平均三层描述、月平均多阶段识别、周期识别和单变量结论。报告事实由本地确定性规则生成。

## V4.2：站点任务与综合报告

已完成并冻结为当前基线。

已完成能力：

- 一个站点任务对应九个独立变量文件；
- 九变量全部上传、读取成功并有效人工确认后，才允许站点综合导出；
- 正式结果仅使用 `final_qc_data`；
- 支持站点综合 Excel；
- 支持站点综合 Word，包含汇总、两张多要素日平均总览图和九变量详细分析；
- 单变量报告继续保留；
- 报告缓存失效规则覆盖数据源、分析范围、QC token、人工决定、重新确认和站点信息变化。

## 下一阶段：报告解读质量评估

目标是对现有确定性报告解读质量进行评估和必要的展示级修订，不改变核心统计口径、质控规则或 `final_qc_data` 数据源原则。

## 明确不纳入路线

- 调和分析；
- 将统计周期解释为潮汐；
- 以大模型替代确定性计算、质控或核心事实判断。
