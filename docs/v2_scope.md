# V2 Scope

## V2 必做

1. 将变量元数据集中到 `src/variable_registry.py`。
   - 中文名
   - 单位
   - 合理范围
   - QC 参数
   - 是否计算月统计
   - 是否计算日变化幅度
   - 需要绘制的图
   - y 轴范围
   - 特殊变量标记

2. 改进质量控制。
   - 物理合理范围
   - Hampel filter
   - 连续恒定值或传感器卡死检测
   - 人工确认

3. 将质量控制独立成明确步骤。
   - 数据上传
   - 数据体检
   - 质控参数配置
   - 原始数据与质控后数据对比
   - 异常点及原因展示
   - 用户确认
   - 后续统计、绘图和导出

4. 增加 QC 日志。
   - 异常时间
   - 原始值
   - 异常原因
   - 使用规则
   - 是否应用
   - 可导出

5. 改进绘图系统。
   - 数字日期格式
   - 统一绘图主题
   - 中文正式报告风格
   - 样式集中配置

6. 减少变量硬编码。
   - 变量下拉框来自注册表
   - 中文名来自注册表
   - 单位来自注册表
   - 图件和统计能力来自注册表

## V2 可选

1. MAD 检测。
2. 滚动中位数检测。
3. 相邻时刻变化率检测。
4. 新增 `salinity`。
5. 新增一个水质变量试点，例如 dissolved oxygen。
6. QC 参数模板。
7. QC 规则敏感性对比。
8. 导出更多中间结果，例如 hourly、daily、anomaly。

## V2 不做

1. AI 报告。
2. MAT 文件读取。
3. 调和分析。
4. 一次性支持全部变量。
5. 云端部署。
6. 数据库。
7. 登录和权限系统。
8. 多用户协作。
9. 生产级任务调度。

## V2 成功标准

1. 用户能理解每个异常点为什么被标记。
2. 用户能在确认质控后再计算结果。
3. 图件日期不再出现英文月份。
4. 新增一个变量时，主要改注册表即可完成基础流程。
5. 质控日志和统计结果可导出。
