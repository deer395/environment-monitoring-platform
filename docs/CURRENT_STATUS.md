## 当前已完成能力

### 站点任务与质量控制

- 一个站点任务对应九个独立监测要素文件：水深、温度、盐度、溶解氧、化学需氧量、生化需氧量、硝酸盐、叶绿素和多环芳烃。
- 支持站点信息录入、九变量上传与状态管理、逐变量自动质量检查、候选异常人工复核及最终质量确认。
- `physical_range` 自动删除且不可恢复；Hampel 与连续恒定值检测仅标记候选，由人工决定删除或保留。
- 候选记录必须全部明确决定后才能完成最终质量确认；正式统计、绘图、Excel 与 Word 报告仅使用确认后的 `final_qc_data`。
- 未上传变量文件时不得静默读取默认文件。
- 站点综合 Excel 与 Word 继续执行严格九变量门槛：站点信息完整、九变量均已上传并读取成功、均具有效人工确认结果且与当前数据源、分析范围及质量控制规则一致。

### 分析与报告交付

- 支持小时平均、日平均、日内距平、日变化幅度、基础统计、月平均与月标准差等既定统计口径。
- 支持单变量 Excel/Word、站点综合 Excel 与站点综合 Word。
- 站点综合 Word 包含站点数据与质量控制汇总、两张多要素日平均总览图及九变量详细分析。
- 报告的数字、月份、方向与统计事实均由本地确定性规则生成；不使用大模型生成或修改核心事实。

### V5.4 高保真 UI

- 已提供九变量任务概览、自动质量检查与人工复核入口、统计分析四个 Tab，以及单变量和站点综合报告交付区域。

## 版本与报告管理状态

- 项目已建立统一版本来源：`src/version.py`。
- 当前版本语义：
  - `BUSINESS_CORE_VERSION = "V4.2"`
  - `BUSINESS_BASELINE_TAG = "v4.2-station-report-complete"`
  - `SINGLE_VARIABLE_REPORT_TEMPLATE_VERSION = "v5.4.1"`
  - `STATION_WORD_REPORT_TEMPLATE_VERSION = "v5.4.1"`
- V4.2 表示业务内核版本；V5.4 表示 UI 与报告模板演进阶段，不得将 UI 版本表述为新的业务算法版本。
- 单变量和站点综合 Word 统一显示“业务内核版本：V4.2”及“业务基线标签：v4.2-station-report-complete”。

### Word 格式与缓存

- 单变量 Word 普通正文首行缩进两个中文字符；标题、图题和表格单元格不首行缩进。
- 站点综合 Word 正文格式保持正常，且与单变量 Word 使用统一版本字段。
- 单变量 Word 已具备模板版本缓存失效机制；站点综合 Word 亦已具备等价机制。
- 站点 Word 模板版本变化时，仅清除站点 Word 字节与文件名；不清除综合 Excel、九变量上传、`final_qc_data`、质量控制、人工复核或质量确认状态。
